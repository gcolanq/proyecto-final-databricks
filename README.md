# Proyecto Final - Ingeniería de Datos con Databricks

## Autor

Gustavo Gonzalo Colan Quiroga

## Descripción

Proyecto desarrollado en Azure Databricks implementando una arquitectura Medallion (Bronze, Silver y Gold) para el procesamiento y análisis de datos comerciales.

## Tecnologías utilizadas

- Azure Databricks
- Apache Spark
- PySpark
- Delta Lake
- Unity Catalog
- SQL
- GitHub

## Arquitectura

### Bronze
Carga de archivos CSV originales.

### Silver
Limpieza, validación y transformación de los datos.

### Gold
Generación de tablas analíticas para la creación de dashboards.

## Objetivos desarrollados

- Carga de datos desde archivos CSV.
- Transformación de datos mediante PySpark.
- Creación de tablas Delta.
- Implementación de Unity Catalog.
- Construcción de consultas SQL.
- Desarrollo de dashboards analíticos.
- Publicación del proyecto en GitHub.

## Dashboards implementados

- Ventas por Ciudad
- Ventas por Producto
- Ventas por Cliente
